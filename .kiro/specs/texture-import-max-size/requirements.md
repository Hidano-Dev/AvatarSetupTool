# Requirements Document

## Project Description (Input)
テクスチャ画像アセットのインポート設定自動調整機能。追加されたテクスチャの実データをファイルパスから読み取り、実際の解像度に最適な Import 設定の最大サイズ (maxTextureSize) を自動調整する。主目的は 4K テクスチャが既定の 2048 で読み込まれて劣化するのを防ぐこと。インポート時の自動設定に加え、プロジェクトビューのファイルまたはフォルダを右クリックして、選択箇所以下の全テクスチャアセットに対して最大サイズが適切かを検証し、必要に応じて修正するメニュー機能も提供する。既存の FbxImportSettingsPostprocessor と同様に com.hidano.avatarsetuptool パッケージの Editor アセンブリに実装する。

## Introduction
本仕様は、Unity エディタ拡張 AvatarSetupTool におけるテクスチャ画像アセットのインポート設定 (maxTextureSize) 自動調整機能を対象とする。テクスチャファイルの実データをファイルヘッダから読み取って実際の解像度を取得し、初回インポート時に実解像度へ最適な maxTextureSize を自動適用することで、4K (4096px) テクスチャが Unity 既定値の 2048 で縮小されて劣化する問題を防ぐ。あわせて、プロジェクトビューの右クリックメニューから、選択したファイル・フォルダ以下の既存テクスチャアセットに対して最大サイズの適否を一括検証し、必要に応じて修正する機能を提供する。既存の FbxImportSettingsPostprocessor / FbxHeaderReader と同様の方針 (初回インポートのみ自動調整・ヘッダのみの軽量読み取り) で、`com.hidano.avatarsetuptool` パッケージの Editor アセンブリに実装する。

## Boundary Context
- **In scope**: 初回インポート時の既定 (Default) インポート設定に対する maxTextureSize の自動調整、プロジェクトビューの右クリックメニューによる選択範囲以下のテクスチャアセットの検証・修正、画像ファイルヘッダからの実解像度読み取りユーティリティ。
- **Out of scope**: プラットフォーム別オーバーライド (Standalone/Android 等) の個別設定調整、圧縮形式・テクスチャタイプ・Read/Write など maxTextureSize 以外のインポート設定の変更、画像ファイル自体のリサイズ・フォーマット変換、ランタイム (ビルドに含まれる) 処理、FBX インポート機能側の変更。
- **Adjacent expectations**: 既存の `FbxImportSettingsPostprocessor` / `FbxHeaderReader` と同一 Editor アセンブリで共存し、それらの既存動作を変更しないこと。解像度読み取り・最適値算出などの主要ロジックは Unity Test Runner (EditMode) で検証可能であること。

## Requirements

### Requirement 1: テクスチャ実解像度の読み取り
**Objective:** アバターセットアップ作業者として、テクスチャファイルの実際の解像度 (幅・高さ) をアセットのファイルパスから取得できるようにしたい。インポート設定の最大サイズを Unity の既定値ではなく実データに基づいて判断するためである。

#### Acceptance Criteria
1. When テクスチャファイルの実解像度が必要になったとき, the テクスチャ最大サイズ調整機能 shall アセットのファイルパスからファイルを直接読み取り、画像の幅と高さを取得する
2. The テクスチャ最大サイズ調整機能 shall 少なくとも PNG・JPEG・TGA・PSD・BMP・GIF・TIFF・EXR・HDR の各フォーマットについて実解像度を取得できる
3. The テクスチャ最大サイズ調整機能 shall 解像度の取得においてピクセルデータ全体のデコードを行わず、ヘッダ近傍の読み取りのみで完了する (巨大なファイルでも高速に動作する)
4. If ファイルが存在しない・内容が壊れている・未対応フォーマットである場合, then the テクスチャ最大サイズ調整機能 shall 例外を呼び出し元の外へ伝播させず、解像度不明として扱う

### Requirement 2: 初回インポート時の maxTextureSize 自動調整
**Objective:** アバターセットアップ作業者として、プロジェクトへ追加したテクスチャの maxTextureSize が実解像度に合わせて自動設定されるようにしたい。4K テクスチャが既定値 2048 で縮小されて劣化するのを、手動操作なしで防ぐためである。

#### Acceptance Criteria
1. When テクスチャアセットが初回インポートされる (インポート設定 .meta が未生成である) とき, the テクスチャ最大サイズ調整機能 shall 実解像度の長辺を包含する最小の maxTextureSize 選択肢 (32/64/128/256/512/1024/2048/4096/8192/16384) を既定のインポート設定に適用する
2. When 4096×4096 の 4K テクスチャが初回インポートされたとき, the テクスチャ最大サイズ調整機能 shall maxTextureSize に 4096 を適用し、既定値 2048 による縮小を発生させない
3. When 実解像度の長辺がいずれの選択肢とも一致しない (2 のべき乗でない) とき, the テクスチャ最大サイズ調整機能 shall 長辺以上で最小の選択肢へ切り上げて適用する
4. If 実解像度の長辺が選択肢の上限 (16384) を超える場合, then the テクスチャ最大サイズ調整機能 shall 上限値 16384 を適用する
5. If 実解像度の長辺が選択肢の下限 (32) 未満の場合, then the テクスチャ最大サイズ調整機能 shall 下限値 32 を適用する
6. While 対象テクスチャが既にインポート済み (.meta が存在する) である, the テクスチャ最大サイズ調整機能 shall インポート時の自動調整を行わず既存設定を保持する
7. If 実解像度を取得できない場合, then the テクスチャ最大サイズ調整機能 shall インポート設定を変更せず Unity の既定動作に委ねる

### Requirement 3: 検証・修正コンテキストメニュー
**Objective:** アバターセットアップ作業者として、プロジェクトビューでファイルまたはフォルダを右クリックし、選択箇所以下の全テクスチャアセットの maxTextureSize が適切かを一括検証・修正できるようにしたい。既にインポート済みの資産に含まれる劣化テクスチャをまとめて是正するためである。

#### Acceptance Criteria
1. The テクスチャ最大サイズ調整機能 shall プロジェクトビューで選択したファイル・フォルダに対する右クリック (コンテキスト) メニュー項目を提供する
2. When メニュー項目が実行されたとき, the テクスチャ最大サイズ調整機能 shall 選択されたファイルおよびフォルダ以下 (サブフォルダ・複数選択を含む) の全テクスチャアセットを列挙し、各アセットの maxTextureSize が実解像度から算出した最適値と一致するかを検証する
3. When 検証で最適値と一致しないアセットが見つかったとき, the テクスチャ最大サイズ調整機能 shall 修正対象の件数と内容を利用者に提示し、確認を得てから修正を適用する
4. When 修正を適用するとき, the テクスチャ最大サイズ調整機能 shall 対象アセットの maxTextureSize を最適値へ変更し、再インポートして反映する
5. When 検証・修正の処理が完了したとき, the テクスチャ最大サイズ調整機能 shall 検証件数と修正件数を利用者へ報告する
6. If 選択範囲にテクスチャアセットが 1 つも存在しない場合, then the テクスチャ最大サイズ調整機能 shall 対象がないことを報告し、設定変更を行わない
7. While 多数のアセットを検証・修正している, the テクスチャ最大サイズ調整機能 shall 進捗を表示し、キャンセル操作を受け付ける

### Requirement 4: エラー処理と副作用の制限
**Objective:** アバターセットアップ作業者として、一部のテクスチャが壊れていたり読み取れなかったりしても処理全体が止まらず、また maxTextureSize 以外の設定や元ファイルが変更されないようにしたい。安心して自動調整・一括修正を使えるようにするためである。

#### Acceptance Criteria
1. If 個々のテクスチャで解像度取得または設定変更に失敗した場合, then the テクスチャ最大サイズ調整機能 shall 当該アセットをスキップして残りのアセットの処理を継続し、失敗した内容をログへ出力する
2. The テクスチャ最大サイズ調整機能 shall 既定インポート設定の maxTextureSize 以外のインポート設定 (圧縮形式・テクスチャタイプ・プラットフォーム別オーバーライド等) を変更しない
3. The テクスチャ最大サイズ調整機能 shall 元の画像ファイル自体を変更しない (読み取り専用でアクセスする)
4. If インポート時の自動調整の処理中に例外が発生した場合, then the テクスチャ最大サイズ調整機能 shall 当該テクスチャのインポート自体は Unity の既定動作で継続させる

### Requirement 5: 実装配置と既存機能との整合
**Objective:** アバターセットアップ作業者として、本機能が既存の AvatarSetupTool パッケージ内で他のインポート支援機能と同じ流儀で動作してほしい。パッケージ導入だけで機能が有効になり、既存機能に影響を与えないためである。

#### Acceptance Criteria
1. The テクスチャ最大サイズ調整機能 shall `com.hidano.avatarsetuptool` パッケージの Editor アセンブリ内に実装され、エディタ実行時のみ動作する (ランタイムビルドに含まれない)
2. The テクスチャ最大サイズ調整機能 shall 既存の `FbxImportSettingsPostprocessor` による FBX インポート処理の動作を変更しない
3. The テクスチャ最大サイズ調整機能 shall 実解像度の読み取りと最適値の算出ロジックを Unity Test Runner (EditMode) の自動テストで検証可能な形で提供する
